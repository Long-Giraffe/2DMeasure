# Batch measurement and locator test data

Generated by `tools/generate_batch_test_images.cpp`.

## How to use

1. Start `measure_app.exe`.
2. Load `recipe.json`. It opens `reference.png` and contains one template locator, two line calipers, one circle caliper, and one cross-caliper bar-width measurement.
3. Open the Batch Test tab, select the `images` folder, and start the batch run.
4. Compare the exported `batch_results.csv` with `expected_results.csv`.

## Dataset intent

- Normal images move the full part together and should be recovered by template localization.
- Noise, blur, brightness, and low-contrast images exercise robustness.
- Circle-large changes the measured diameter.
- Bar-wide changes the right edge and intentionally invalidates the stored bar-width edge pair.
- Missing or corrupted objects exercise NG handling.
- The recipe uses Gray channel and a calibration of 0.05 mm/px.
