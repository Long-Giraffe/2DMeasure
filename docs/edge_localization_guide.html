工业卡尺边缘定位：从像素级到亚像素级

本方案将二维图像中的卡尺区域转换为一维灰度剖面，通过平滑、导数响应、阈值筛选和亚像素精修获得边缘位置。 对于稳定、清晰的 0 ↔ 255 阶跃边缘，边界应落在相邻像素中心之间，因此结果自然是 .5，而不是某个整数像素中心。

核心结论：理想的 255 → 0 或 0 → 255 边缘不需要人为加 0.5。 算法在像素中心坐标系中，通过中灰值穿越计算出真实的 .5 边界；固定补偿会使其他亚像素边缘产生系统偏差。

1. 坐标定义：像素中心与边界

精确定位首先要统一坐标语义。OpenCV 图像索引表示像素中心，而物理边界位于像素单元之间。

像素中心坐标示意

示例：白色像素 79 与黑色像素 80 之间
真实边界 x = 79.5
255x = 77
255x = 78
255x = 79
0x = 80
0x = 81

像素中心坐标

图像数组中的 image(y, x) 对应坐标 (x, y) 的像素中心。整数坐标不是像素左上角，而是采样值所在的位置。

像素单元边界

像素 x = 79 覆盖近似区间 [78.5, 79.5)，像素 x = 80 覆盖 [79.5, 80.5)，所以两者边界为 79.5。

Qt 绘制时可能需要在显示坐标边界进行 ±0.5 转换，以对齐画笔和像素格；这属于显示坐标转换。 检测算法内部的边缘坐标不能统一加 0.5。

2. 完整边缘定位流程

当前实现采用“稳定候选发现 + 原始剖面精修”的双阶段策略。

STEP 01

扩展扫描线

按滤波核支持范围增加 padding，避免端点附近的卷积响应被截断。

STEP 02

提取灰度剖面

沿扫描方向每 0.25 px 双线性采样，并在卡尺宽度方向求平均。

STEP 03

发现候选边缘

平滑剖面后计算高斯导数，按极性和阈值找到连续响应段。

STEP 04

亚像素定位

优先在原始剖面中寻找中灰值穿越；条件不满足时拟合导数峰值。

STEP 05

映射回图像

去除 padding，将一维位置沿卡尺单位方向转换为二维边缘点。

扫描与采样

padding = max(0, 3σsmooth + 3σderivative + 2Δs)
P(s) = meant ∈ width I(p1 + s·u + t·v)

其中 u 为卡尺扫描方向，v 为垂直方向，Δs = 0.25 px。宽度方向求平均可以降低随机噪声，同时保留沿扫描方向的边缘位置。

候选与精修

G(s) = d/ds [ Gaussian(σ) * P(s) ]
pedge = p1 + u · sedge

正梯度表示 0 → 255，负梯度表示 255 → 0。阈值筛选保留真正的响应段，再由中灰值穿越或导数峰值给出亚像素坐标。

// 当前实现的关键策略
rawProfile     = extractProfileAlongLine(..., sampleSpacing = 0.25);
smoothProfile  = gaussianSmooth(rawProfile, profileSmoothSigma);
gradient       = gaussianDerivative(smoothProfile, derivativeSigma);
candidates     = findThresholdSegments(gradient, polarity, thresholds);

for (candidate : candidates) {
    edge = refineProfileMidpointCrossing(rawProfile, candidate);
    if (!edge.valid)
        edge = fitQuadraticSubpixel(gradient, candidate.peak);
}

理想 255 → 0 示例

left = 255, right = 0, midpoint = (255 + 0) / 2 = 127.5
x = 79 + (127.5 - 255) / (0 - 255) = 79.5

双线性插值使像素中心之间的灰度连续变化，因此中灰值穿越自然得到 79.5。

理想 0 → 255 示例

left = 0, right = 255, midpoint = (0 + 255) / 2 = 127.5
x = 79 + (127.5 - 0) / (255 - 0) = 79.5

边缘极性只决定梯度符号，不改变几何边界位置。两个方向都应得到相同的 .5 坐标。

保证范围：只有当边缘两侧平台稳定、对比度足够、边缘方向与梯度极性一致，并且中灰值穿越可被可靠找到时，理想阶跃才应精确落在 .5。 噪声、反光、阴影、过曝、光学模糊或非对称灰度过渡都会改变实际定位定义。

4. 如何保证精确定位

算法分辨率只是基础，最终准确度由采样、信号质量、定位定义、标定和机械稳定性共同决定。

算法层

  • 0.25 px 过采样，避免只在整数点比较。
  • 卡尺宽度方向求平均，降低随机噪声。
  • 扫描线 padding，保护端点边缘的滤波响应。
  • 平滑剖面只用于发现候选，原始剖面用于精修。
  • 中灰值条件不可靠时，降级为导数峰值拟合。

成像层

  • 保持照明均匀，减少阴影和高光。
  • 避免曝光饱和，保留边缘两侧灰度差。
  • 确保对焦稳定，控制景深与运动模糊。
  • 卡尺方向尽量垂直于目标边缘。
  • 选择对比度最高、最稳定的颜色通道。

测量系统层

  • 使用标定板建立 px 与实际单位关系。
  • 修正镜头畸变和透视误差。
  • 固定相机、镜头、光源和被测物姿态。
  • 用重复测量评估 3σ 波动与偏差。
  • 用已知尺寸样件验证准确度，而非只看重复性。
亚像素分辨率不等于亚像素准确度。 算法可以输出三位小数，但如果光学、标定或机械系统存在偏差，结果仍然可能不准确。必须同时评估重复性、线性、偏差和现场环境稳定性。

原始剖面中灰值精修的可靠性条件

5. 参数设置建议

参数应以实际图像的噪声、边缘宽度和目标结构为依据，避免用同一组数值覆盖所有场景。

参数作用建议过大或过小的影响
width 垂直扫描方向的平均宽度 平直边缘可适当增大；弯曲或局部边缘应减小 过大可能混入其他结构，过小则抗噪不足
profileSmoothSigma 剖面平滑 干净阶跃使用较小值，噪声高时适当增大 过大会合并近距离边缘，过小会产生伪峰
derivativeSigma 导数核尺度 与实际边缘过渡宽度匹配 尺度不匹配会降低响应或改变峰值位置
positiveThreshold 0 → 255 的最小梯度 高于背景噪声梯度，低于目标边缘响应 过高会漏检，过低会引入纹理伪边缘
negativeThreshold 255 → 0 的最小梯度 按负梯度幅值设置，与正阈值分开校验 符号或幅值错误会使亮到暗边缘漏检
polarity 限定边缘方向 已知目标明暗关系时使用明确极性 使用 Any 会增加错误边缘被选中的概率
selection First / Last / Strongest 根据目标结构选择，不要仅依赖 Strongest 反光或纹理可能比真实边缘更强
调参顺序建议：先确定卡尺方向和宽度，再观察原始灰度剖面，随后设置极性和阈值，最后微调平滑与导数尺度。
不要用固定 +0.5 修正结果：它只能碰巧修正某一种错误坐标解释，却会对已经正确的亚像素边缘增加 0.5 px 系统偏差。

6. 常见异常与排查

定位不稳定时，先判断问题来自信号、参数、几何还是坐标转换。

0 / 255 阶跃没有定位到 .5
检查原始图像是否真的是相邻像素中心一个为 0、另一个为 255；确认卡尺是否垂直穿过边缘；确认中灰值精修是否因平台不稳定而降级为导数峰值；检查结果是否在显示层又被加减了 0.5。
边缘位置随卡尺宽度变化
目标边缘可能不平直、存在倾斜、曲率、纹理或照明不均。宽度方向求平均会改变剖面形状。缩小宽度，或调整卡尺方向使其更垂直于目标边缘。
边缘位置随平滑参数变化
实际边缘可能不是对称过渡，或附近存在第二条边缘。平滑尺度改变后，导数峰值会移动或合并。优先检查原始剖面和附近结构，并避免过度平滑。
前向扫描和反向扫描结果不同
检查极性是否随方向正确解释，检查 First / Last 选择模式是否仍指向同一物理边缘，并确认端点 padding 和扫描长度裁剪正确。
算法重复性好，但实际尺寸偏差大
这是准确度问题，通常与像素标定、镜头畸变、透视、被测物高度变化或机械安装有关。使用已知尺寸样件做多位置标定验证。

8. 与当前代码的对应关系

后续维护或交给其他 AI 修改时，可从以下文件和函数开始定位。

src/core/CaliperDetector.h 检测器接口、结果结构和 kProfileSampleSpacing = 0.25 定义。
src/core/CaliperDetector.cpp 扫描线扩展、双线性采样、剖面提取、导数计算、候选边缘发现、中灰值精修和二维坐标映射。
refineProfileMidpointCrossing() 在原始剖面上计算左右平台、中灰值和穿越点，是理想 0 ↔ 255 边缘定位到 .5 的关键。
fitQuadraticSubpixel() 当中灰值精修不满足可靠性条件时，对导数峰值进行二次曲线亚像素拟合。
tools/edge_bias_probe.cpp 构造理想黑白阶跃边缘，验证 255 → 0 和 0 → 255 的边界偏差。
caliper_validation_results.csv 记录当前合成图验证的测量值、期望值、误差和通过状态。
修改算法时建议保留三条约束：内部坐标继续使用像素中心坐标；理想黑白阶跃必须回归到 .5；绘制层坐标转换不能反向污染检测结果。
